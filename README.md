# Biplane Game

Лабораторна робота 2: «Об’єкти, прототипи та this: модель сутностей».

Браузерна гра: пастельний біплан, яким літаєш по арені на canvas. 
- [lab-01](https://github.com/Sol777xxx/biplane-game/tree/lab-01): ігровий цикл, фіксований крок, експерименти з event loop.
- lab-02: об'єкти, прототипи та `this` (у роботі).

## Запуск

```
npm install
npm run dev
```

Потрібен Node.js 24 (див. `.nvmrc`). Гра відкривається за адресою `http://localhost:5173/`.

Перевірка коду: `npx biome check .`

## Керування

| Клавіша | Дія |
|---|---|
| ← → ↑ ↓ або WASD | рух |
| H | показати або сховати HUD |
| P | вимірювання: 5 с польоту вправо, результат у консолі браузера |
| Пробіл | стрільба|

Героя в кабіні обирають на панелі у правому верхньому куті. Вибір зберігається в `localStorage`.

## Архітектура

```
src/
  loop.js      ігровий цикл (rAF + акумулятор)
  input.js     клавіатура як замикання
  main.js      збірка
  sim/         модель світу: вектори, сутності, біплан (без DOM)
  render/      малювання на canvas, герої в кабіні
  ui/          панель вибору героя

```
